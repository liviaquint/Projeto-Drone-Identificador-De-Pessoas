# Projeto-Drone-Identificador-De-Pessoas

# Drone Identificador de Pessoas em Desastres Ambientais

* **Nome:** Lívia Quintilhano Nogueira

---

## Objetivo
Desenvolver um sistema de programação integrado a um drone, capaz de identificar pessoas em ambientes afetados por desastres ambientais, como enchentes, deslizamentos de terra e áreas de difícil acesso. 

O projeto utiliza uma câmera embarcada no drone para realizar a captura de vídeo em tempo real, que é submetido a técnicas de processamento de imagens. O sistema tem como finalidade detectar e identificar a presença de pessoas nas áreas monitoradas, auxiliando equipes de resgate na localização de possíveis vítimas e contribuindo para tornar as operações de busca mais rápidas, seguras e eficientes.

---

## Como Funciona
1. **Captura:** O drone sobrevoa a área afetada e utiliza uma câmera para capturar vídeo em tempo real.
2. **Transmissão:** As imagens são enviadas para o sistema de programação.
3. **Processamento:** O sistema realiza a análise dos frames do vídeo para detectar a presença de pessoas.
4. **Identificação:** Quando uma pessoa é localizada, o sistema identifica e destaca as pessoas presentes no local para a equipe de monitoramento.

---

## Desenvolvimento
O desenvolvimento do projeto consiste na integração do drone com uma câmera responsável pela gravação de vídeos durante o sobrevoo de áreas afetadas por desastres ambientais. 

Os vídeos captados são enviados para o sistema de programação, que realiza o processamento e a análise dos frames para detectar a presença de pessoas. A partir dessa identificação, o sistema apresenta os resultados na tela, permitindo analisar a localização de possíveis vítimas e demonstrar na prática como a tecnologia pode auxiliar as equipes de resgate em áreas de difícil acesso.

## Testes e Validação
Para realizar os testes do projeto, convidamos alunos do Ensino Fundamental II para participar de uma simulação de desastre ambiental. 

Durante a atividade, foi produzido um vídeo representando uma situação de emergência, com pessoas posicionadas em diferentes pontos da área simulada. O drone realizou a gravação dos vídeos, que posteriormente foram utilizados para testar o sistema de processamento e detecção de pessoas. Dessa forma, foi possível verificar o funcionamento prático do projeto em um cenário muito próximo ao real.

---

## Conclusão
O desenvolvimento do drone identificador de pessoas demonstra como a tecnologia pode ser utilizada como uma ferramenta humanitária crucial para auxiliar equipes de resgate em situações de desastres ambientais. Por meio da captura de vídeos e do processamento inteligente das imagens, o sistema busca detectar pessoas onde o acesso humano é perigoso ou demorado. O projeto apresenta uma solução viável para tornar a busca por vítimas mais ágil, aumentando as chances de salvamento e protegendo as equipes de resposta.
